# Web Development Assignment #2: Flexbox & CSS Grid

This repository contains the completed tasks for **Assignment #2**, exploring layout building using **Flexbox** and **CSS Grid**. The project features custom color palettes, modern typography, and clean structured layouts.

## Live Demo

You can check out the live website here:
[GitHub Pages Link](https://parasatashk.github.io/Assignment2_Web_Parasat/)

---

## Pages & Tasks Included

### Part 1: Flexbox Layouts

- **`index.html`** — Navigation bar created with Flexbox and responsive content sections.

### Part 2: Grid Layouts & Gallery

- **`grid.html`** — Clean page structure built entirely using CSS Grid.
- **`gallery.html`** — Responsive 3x3 image gallery with custom hover overlay captions, styled using an aesthetic night-life neon palette.

### Part 3: Combining Flexbox & Grid

- **`portfolio.html`** — Portfolio layout featuring:
  - **Header:** Flexbox navigation bar.
  - **Main Content:** CSS Grid dividing the page into a 3-column project showcase and a 1-column sidebar.
  - **Project Cards:** Flexbox inside each card to keep titles, descriptions, and action buttons aligned.
  - **Footer:** Full-width footer pinned to the bottom.
  - **Color Palette:** Custom olive, pistachio, strawberry cream, cocoa, and deep burgundy theme.

## Built With

- **HTML5** — Semantic page structure
- **CSS3** — Flexbox, CSS Grid, custom variables, and responsive hover effects
- **Google Fonts** — _Playfair Display_, _Montserrat_, and _Syne_
